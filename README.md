## Overview

**JanSetu** is a web-based Rural Panchayat Grievance Management System developed to make public grievance handling more accessible, transparent, and accountable.

Traditional grievance-handling processes often involve manual communication, limited tracking, and delays in resolution. JanSetu addresses these challenges through a centralized digital platform that connects citizens, Panchayat administrators, and field workers within a structured grievance resolution workflow.

From complaint registration to assignment, progress monitoring, and resolution verification, the platform brings the entire process into one accessible system.

## Core Capabilities

| Module | Description |
|---|---|
| Citizen Portal | Register grievances and monitor their status. |
| Administration | Review complaints, manage assignments, and oversee resolutions. |
| Worker Portal | Access assigned tasks and submit progress updates. |
| Grievance Tracking | Track complaints through unique reference IDs. |
| Resolution Verification | Review submitted evidence before grievance closure. |
| Analytics Dashboard | Visualize grievance statistics and performance. |
| Language Support | English and Telugu interface support. |

## System Workflow

1. **Registration** — Citizens submit grievances through the platform.
2. **Review** — Administrators examine and categorize submitted complaints.
3. **Assignment** — Grievances are assigned to relevant field workers.
4. **Execution** — Workers address the reported issues and update progress.
5. **Verification** — Submitted work evidence is reviewed.
6. **Resolution** — The grievance status is updated upon completion.

## Project Objectives

- Digitize rural public grievance management.
- Improve accessibility to Panchayat services.
- Establish a transparent complaint-tracking mechanism.
- Strengthen coordination between citizens and administration.
- Promote accountability through structured assignment and verification.
